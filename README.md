## `>` how I work

| | |
|---|---|
| **Honest metrics** | Speaker-independent evaluation over the leaky random split that inflates every number you've seen. Provenance labels on every reported figure — `Measured` vs `Model estimate` vs `NOT MEASURED`. |
| **Degrade, don't die** | Confidence gates with deterministic fallbacks. RAG that drops to keyword scoring when the vector stack is down. The report always ships. |
| **Latency is a feature** | 4.1× end-to-end reduction by restructuring for streaming and parallel execution — not by buying a bigger GPU. |
| **Known limitations, written down** | Every repo carries an honest inventory of what's broken and what's missing. Engineering is what you did *and* what you know you didn't. |
